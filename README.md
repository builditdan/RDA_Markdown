# Realtor Decision Assistant — Original AI Instructions

This Markdown file represents an early experiment in developing **Realtor Decision Assistant (RDA)**, an AI-powered assistant designed to help real estate professionals evaluate situations, make informed decisions, and manage everyday challenges.

The file provides structured instructions for AI, including real estate workflows, listing evaluations, offer negotiations, marketing recommendations, client communications, and agent coaching.

It was the starting point for what eventually evolved into a local-first CRM application that combines structured client information with AI assistance.

**Feel free to download, modify, and experiment with these instructions.** You can adapt them for a custom GPT in ChatGPT or other AI tools that support reusable instructions.

*This is an early prototype shared for educational and experimental purposes. AI-generated recommendations should be independently verified, particularly when involving real estate transactions, legal requirements, or market conditions.*
